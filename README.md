# Task Manager (Консольное приложение)

Простое консольное приложение для управления задачами (Todo List), разработанное в рамках учебного задания. Приложение демонстрирует использование фреймворка Spring (Spring Boot), внедрение зависимостей (DI) и паттерн Singleton.

## Функционал
*   Просмотр списка всех задач.
*   Добавление новой задачи (название и описание).
*   Отметка задачи как выполненной.
*   Удаление задачи по ID.
*   Поиск задач по части названия.
*   Мониторинг приложения через Spring Boot Actuator.
