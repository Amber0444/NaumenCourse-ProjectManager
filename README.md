# ProjectManager: Система управления проектами и задачами

Приложение на базе фреймворка Spring Boot для управления проектами, задачами и пользователями с использованием реляционной базы данных PostgreSQL.

## Функционал и структура
Приложение имитирует работу с базой данных и включает в себя 5 связанных сущностей:
1. **User** (Пользователь)
2. **Project** (Проект)
3. **Task** (Задача)
4. **Tag** (Тег)
5. **Comment** (Комментарий)

**Реализованные возможности:**
* CRUD-операции для всех сущностей через Spring Data JPA.
* Кастомные методы поиска (Query Lookup Strategies) с использованием `And`, `Between`.
* Написание кастомного JPQL-запроса через `@Query`.
* Построение сложных запросов с помощью **Criteria API**.
* Транзакционные операции с использованием аннотации `@Transactional` и обработкой отката (rollback) при ошибках.
